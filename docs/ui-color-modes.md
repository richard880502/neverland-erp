# 深色／淺色模式與介面修補

登入頁與導覽列提供「跟隨系統」「淺色模式」「深色模式」。第一次使用依系統設定顯示；明確選擇存於瀏覽器 `localStorage` 的 `neverland-theme`。改回跟隨系統會移除此值。系統模式會即時回應系統偏好變更，同一來源的其他分頁也會同步使用者選擇。

`lib/color-theme.ts` 的初始化腳本在頁面內容繪製前套用 `data-theme` 與 `data-theme-preference`。`components/ThemeToggle.tsx` 負責操作與同步；儲存空間受限時仍可在目前頁面切換。

`app/color-modes.css` 最後載入，定義兩種模式的語意色彩與舊介面相容規則。新增元件請使用 `--ui-bg-*`、`--ui-fg-*`、`--ui-border-*` 與 `--ui-chart-*`，並避免在元件內寫死白色背景。主按鈕、成功／警告／錯誤狀態與圖表各自使用獨立配色。圖表與 CSS 動畫均尊重減少動態效果偏好。

本次一併修正：

- 儀表板篩選欄在 1280px 視窗撐寬整頁，改用可縮放與換行的格線。
- 圖表及請款詳情的並排卡片受到垂直堆疊 margin 影響。
- KPI 數值與比較文字共用絕對定位空間。
- 日期清空或輸入超出範圍後，計算收到無效日期。
- 手機側欄隱藏登出，及部分輸入框／操作目標過小。
- 鍵盤焦點不清楚、搜尋框焦點消失，並新增跳至主要內容連結。
- 登入卡片寬度與外層 padding 的不一致。
- 次要文字、圖片預留文字與同步設定提示的對比不足。

驗證方式：`npm test`（含主題初始化測試）、`npm run lint`、設定 `DATABASE_URL` 後執行 `npm run build`。瀏覽器回歸應確認 375／768／1024／1280／1440px，並檢查主題持久化、系統偏好、分頁同步、鍵盤操作、日期清空與減少動態效果。

設計參考：[UI/UX Pro Max](https://github.com/nextlevelbuilder/ui-ux-pro-max-skill)。本次採用其可讀性、響應式、語意色彩、鍵盤焦點及動態效果規則，保留既有 Medusa 風格。
