# 經銷出貨表 V1 範本

每個經銷通路須各自設定工作簿 ID 和範本頁籤，並授權既有 Google Sheets 服務帳號。系統不使用預設工作簿。請建立空白範本，將 BA1 設為 `NEVERLAND_SHIPMENT_TEMPLATE_V1`，A2:G2 依序設為 `品項`, `S`, `M`, `L`, `XL`, `2XL`, `F`。可在範本中預設格式；不要合併 ERP 資料區儲存格。

ERP 擁有 A1:AY1000 和 BA1:BA2，每次更新會清除並重寫 A1:AY1000；合計列的「運費」欄是本次向通路回收的運費（未填則顯示「待確認」）；BA 欄存放範本版本和出貨單識別。人工記錄請放在 BC 欄或其右側，系統不會改寫。資料按品名、售價和交易價分組，其他尺寸會增加欄位。建立／更新工作表是明確動作，不會出貨或更動庫存。若已連結的頁籤遭刪除或取代，系統會拒絕更新並要求人工處理。
